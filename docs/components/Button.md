# Button
Primary and secondary actions, taken from the bytes.coffee hero.

Provide: a short label in sentence case ("Read the blog", "Play Bad Decisions"). Add ↗ when it leaves the site.

- One `bc-btn-primary` (`orange-fill` with `on-accent` text) per view; everything else is the outlined `bc-btn`.
- Buttons sit on `elev-button` and drop into their shadow when pressed.
- Inline links in text use `bc-link` (`orange-dark`, underlined), never orange.
- Focus: 2px `orange-dark` ring, offset 2px.
