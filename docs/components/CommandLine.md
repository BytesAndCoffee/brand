# CommandLine
A shell command in a terminal chip, plus feature tags. Used on the GitHub preview, the blog and slides.

Provide: the exact command, copyable. The `$` prompt is `orange-dark` and isn't part of the copied text.

- `panel-sunk` fill, `line` border, `radius-md`, `code` style.
- Feature tags are pill-shaped `cream` chips in DM Mono. Three or four at most.
