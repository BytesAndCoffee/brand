# Logos
Avatars built from the marks. Both are raster PNGs on the `page` ground and survive a circle crop.

- `bytes-coffee-avatar.png`: the B tile in `ink` with an `on-ink` B and an `orange` underline bar. Use for Bytes & Coffee profiles (Gravatar, GitHub, Bluesky @bytes.coffee).
- `daily-regrets-avatar.png`: the Daily Regrets calendar page, an `orange` card with an `accent-deep` strip and an italic R. Use only for the Daily Regrets bot.

There is no vector logo yet. Build the wordmark from the Wordmark component (live type), and don't trace or redraw these PNGs.
